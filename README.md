# amazon-sales-sql-analysis
# Amazon Sales Analysis using SQL

## Project Overview

This project analyzes 205,956 Amazon sales records using SQL to uncover revenue trends, customer behavior, product performance, and geographical sales insights.

## Project Architecture

Amazon.csv Dataset
        ↓
Data Import using DBeaver
        ↓
MySQL Database (amazon_project)
        ↓
SQL Queries & Analysis
        ↓
Business Insights & Findings

## Tools Used

- MySQL
- DBeaver
- SQL

## Dataset Information

- Records: 205,956
- Columns: 20
- Domain: E-commerce Sales

## Business Questions Answered

1. What is the total revenue?
2. Which category generates the highest revenue?
3. Which brand generates the highest revenue?
4. Who are the top customers?
5. Which products sell the most?
6. What is the cancellation rate?
7. What is the delivery success rate?
8. Which state, city, and country generate the highest revenue?
9. Which payment methods are most preferred?

## Key Insights

- Total Revenue: ₹189,090,625.22
- Top Category: Electronics
- Top Brand: Core Tech
- Best Selling Product: Memory Card 128GB
- Top State: Texas (TX)
- Top City: Dallas
- Cancellation Rate: 3.03%
- Average Order Value: ₹918.11
